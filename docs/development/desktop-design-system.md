# Lanveriq 原生桌面设计系统

**ACTIVE SPEC · 2026-11-28 · MVP-08 · 开发规范，非发布批准。**

唯一原生桌面候选：Rust + GPUI Kit 0.11.0 / GPUI 0.3.14；以维护者 Pop!_OS 24.04 KDE Plasma/X11 为首要本机环境。KDE/Wayland、COSMIC/Wayland 和 Windows/macOS 分别验收。Web 仍遵循独立的 [Web 设计系统](frontend-design-system.md)，不引入 WebView 或第二套桌面 GUI。架构、安全及回退以 [ADR-0014](../architecture/adrs/0014-gpui-desktop-candidate.md) 为准。

## 1. 产品方向与页面职责

原生、清晰、安静、紧凑的设备管理工具。主任务优先，不为装饰增加复杂度。每页一个主要任务，状态与操作分离，不重复整套元数据。

| 固定四字导航 | 稳定 ID | 页面职责 | 后续业务（未实现或未授权） |
| --- | --- | --- | --- |
| 设备概览 | overview | OS/内核/CPU/RAM、运行摘要、手动刷新 | GPU、磁盘、网络的明确获批本机信息 |
| 安装向导 | setup | 兼容预检、七门禁与四项说明 | 分步安装/取消/升级/卸载 |
| 连接配置 | configuration | 服务器未知状态、空闲周期草稿 | 真实服务器设置、连接检测与保存 |
| 设备注册 | enrollment | 未核验的注册与凭据状态 | 受审注册、证书与凭据生命周期 |
| 代理服务 | service | 软件包、systemd、旧文件元数据 | 明确授权的启停/自启与资源监控 |
| 安全诊断 | diagnostics | 图形预检、可选取的脱敏报告 | 受审错误与诊断输出 |
| 关于软件 | about | 版本、主题、合成 IME 测试 | 许可、更新、持久化外观 |

菜单、页标题、无障碍名称和折叠提示共享四字标签；ID、图标、顺序稳定。不得把未实现的动作显示为可用。

## 2. 布局和尺寸

所有尺寸为逻辑像素，服从原生窗口管理器与用户缩放。保留系统标题栏、关闭与焦点行为，不自绘窗口控制按钮。

| 属性 | 规范 |
| --- | --- |
| 默认窗口 | 1200 × 800；允许系统限制，不强制最小屏幕尺寸 |
| 左侧展开 / 折叠 | 200 / 48（上游 Sidebar 固定 48；不 fork 以强做 56） |
| 折叠断点 | viewport width < 760；恢复时保留当前页 |
| 菜单 | 40 行高、18 图标槽、14 正文基准、四汉字；水平左起，垂直居中；折叠图标居中 |
| 页面 | 24 标题、16 卡片标题、14 正文、13 辅助文字；内容最大宽 1120 |
| 空间 | 桌面页边距 24、窄窗 12；主要区域 gap 16、卡片内边距 16 |
| 卡片/颜色 | 原生 GPUI Kit 主题 radius、border、background、muted；不写死主题颜色或伪造在线绿点 |
| 滚动 | 内容区独立滚动；底部状态栏固定，侧栏使用上游 Sidebar 自身布局 |
| 工具栏 | 页面标题/描述左起，当前页唯一手动刷新按钮靠右；窄窗自然换行 |

概览先显示真实核心数、总内存、可用内存三张指标卡，后显示系统详情和简短运行状态；窄窗允许卡片换行。GPU/磁盘/网络暂不增加伪数值卡片。安装与诊断显示图形兼容预检；代理服务显示原始服务状态；其余页面保留各自业务。统一底部显示非发行、只读、未授权提示；不在每页顶部重复同一横幅。

## 3. 状态、交互和安全

- 未检测/失败/缺失：显示未核验，不能解释为零或离线；合法零值仅在真实数据可确认时展示。
- 刷新：显式手动，清空旧摘要与通知确认，显示进行中，禁用重复刷新；只在内存保存返回结果，页面切换保留该次摘要。
- 已读说明、配置草稿、主题与输入框仍按 ADR 现有生命周期。草稿/说明离页重置；主题本次运行有效；IME 不保存。持久化偏好后续独立任务。
- Tab/Shift+Tab、Enter/Space、Ctrl+Q、折叠提示和可见焦点；图标不替代无障碍名称。真实 DPI/IME/辅助技术另验。
- 十个受限操作按 3/2/2/3 分布，始终禁用，给出理由；不得创建 root GUI、联网、安装、启动服务、自动采集、上传或修改系统。允许的本机手动 OS/CPU/RAM 摘要仅显示，不进入脱敏报告。

## 4. 实施顺序和验收

P0：统一壳层/导航/刷新/概览及状态分布（本轮源码）；确保实际 CPU/RAM 快照、错误状态和原生响应式验收。P1：在授权任务内优化安装向导、配置和诊断；GPU/磁盘/网络先审数据范围及成熟库。P2：真实偏好持久化、辅助技术与其他桌面专项验收。禁止为了新视觉反复换框架或扩大 MVP-08。

完成标准：确切源码 SHA 的模型、原生构建、合成 X11 键盘/主题/缩放及包审查通过；维护者现有 KDE/X11 的真实窗口验证四字、对齐、刷新后真实数据、窄窗滚动与退出，不把合成截图或源码视为视觉验收。已有七项所有人观察保留，不代填未测项目。独立 L3、许可证、发行与权限审批仍分开，G-01–G-10 OPEN，v0.1 NOT RELEASE READY。进度只记 [本机任务账本](../planning/local-mvp-tasks.md) 与 [CURRENT_STATUS](../CURRENT_STATUS.md)，本规范不重复 CI 日志。
