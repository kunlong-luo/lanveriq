# v0.1 implementation sequence (planning only)

**Rule:** document-first, then direct atomic commits to main; no feature branches, no E2E or release automation; add real unit tests alongside each code unit.

## Phase 0: D0 review
- Review PRD, endpoint event contract, policy/notice scope, initial Windows/Linux target, bootstrap CA and device-key approach.
- Resolve or intentionally record blockers in [open decisions](../governance/open-decisions.md).
- No implementation code until maintainer approves D0. No real employee data before additional organizational approvals.

## Suggested dependency order
| Order | Ticket | Deliverable | Exit evidence |
|---|---|---|---|
| 01 | ARCH-01 | Freeze `event_type` envelope, identity and atomic batch-ack protocol | docs accepted, examples and negative cases reviewed |
| 02 | SRV-01 | Spring Boot 4 skeleton + PostgreSQL 18 + Flyway + HTTPS dev bootstrap | local start / migration manual check; real unit test |
| 03 | SRV-02 | Admin bootstrap, short-lived one-use enrollment, device revocation | token expiry/replay unit tests |
| 04 | AGT-01 | Rust service skeleton, config and OS service install approach | Windows/Linux service manual smoke |
| 05 | AGT-02 | SQLite single writer + atomic cursor and outbox migration | replay/durability unit tests |
| 06 | SRV-03 | Transactional, all-or-nothing event batch ingestion | dedup, conflict, malformed batch unit tests |
| 07 | AGT-03 | Verified TLS, device auth, heartbeat + bounded retry/outbox upload | manual LAN failure/reconnect, unit retry tests |
| 08 | WEB-01 | React/Vite dashboard with admin login and device list | UI unit tests for state and permissions |
| 09 | OPS-00 | Minimal restore, access scope and log/credential audit review | dated manual checks; no real data until passed |

## Suggested small commit slices
- Define types and versioned envelope (docs / minimal shared contracts).
- Create PG migrations for admin/enrollment and unique device/event keys.
- Unit test single-use token and wrong-device denial.
- Build Rust local SQLite schema, then writer actor and synthetic event uploader.
- Expose server heartbeat/event route and dashboard inventory query.
- Integrate real Windows/Linux heartbeat (no screen capture yet).
- Complete two-device manual smoke and document outcomes.

## MVP v0.1 deliberately excludes
Applications/window timeline, Windows Sysmon integration, Linux auditd ingestion, recording/playback, WebRTC, remote command execution, installer auto-update, AI, microservices, Redis, Kafka, E2E and exhaustive CI. These belong to later specified milestones.

## Key milestone definition
A v0.1 demo must show **one Windows 11 + one selected Linux endpoint → authenticated server → PostgreSQL → React device list**, then survive an induced temporary LAN outage with replay and duplicates not duplicated. If any step is missing, milestone remains incomplete.
